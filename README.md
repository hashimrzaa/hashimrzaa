## 🧠 Engineering highlights

- 🔐 **No double bookings:** stock is taken with atomic conditional updates inside transactions, with hold-and-commit for partner bookings
- 🏢 **Tenant isolation:** each supplier only sees its own data through EF Core global query filters and JWT claims
- 🔌 **Partner API:** search, prebook and confirm with idempotency keys, so retries never create duplicate bookings
- 🚀 **Shipping:** Docker Compose and GitHub Actions deployments to VPS, plus cPanel and Vercel
